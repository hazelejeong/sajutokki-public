시행일: 2026년 11월 10일 · Android cc.myonward.kr

운영자와 적용 범위

사주토끼의 운영자는 RottenRopes · Hazel Jeong입니다. 개인정보 및 서비스 문의: support@myonward.cc.

기기 안에서 처리하는 정보

이름, 생년월일, 양력·음력·윤달 여부, 태어난 시간, 궁합 상대 정보, 선택한 운세·타로와 저장한 풀이, 편지 답장 및 일기를 기기에서 처리합니다. 프로필 없이도 카탈로그와 타로를 이용할 수 있습니다. Android 앱의 로컬 저장소(Preferences), 웹의 localStorage에 보관하며 운영 서버로 전송하지 않습니다.

이용 목적과 외부 전송

생일로 간지와 자체 풀이를 계산하고 사용자가 선택한 기록을 다시 보여주는 용도로만 사용합니다. 계산은 기기 안에서 수행합니다. 광고, 분석 SDK, 외부 AI, 로그인, 푸시 알림을 사용하지 않으며, 앱은 개인정보를 수집하거나 판매·공유하지 않습니다. Android 앱의 콘텐츠는 앱에 포함되어 오프라인으로 사용할 수 있습니다.

공유와 백업

운세 공유는 콘텐츠 또는 앱 소개 주소만 전달합니다. 이름·생일·질문·개인 결과는 공유 주소에 포함하지 않습니다. 사용자가 별도로 선택한 기록 백업 파일과 코드는 개인 기록을 포함합니다. 사용자가 고른 앱·저장 위치로만 직접 내보내며 운영자는 받지 않습니다. Android의 내보내기용 임시 파일은 공유 후 삭제됩니다. 백업은 안전한 곳에 보관해 주세요.

보관, 열람, 수정과 삭제

내 정보에서 프로필을 수정하고 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 앱 데이터·브라우저 데이터를 지우거나 앱을 삭제해도 기기 기록이 삭제됩니다. 계정이나 서버 백업은 없고 Android 자동 클라우드 백업도 사용하지 않습니다. 기기 변경 시 직접 백업과 복원이 필요합니다. 별도 내보낸 백업은 해당 앱·저장 위치에서 직접 삭제해 주세요. 운영자는 기기의 기록에 접근하거나 이를 복구할 수 없습니다.

외부 페이지와 문의

소개·정책 페이지를 열면 GitHub Pages 등 해당 호스트에 IP 주소 등 기본 접속 기록이 남을 수 있습니다. 해당 기록은 호스팅 제공자의 개인정보처리방침에 따릅니다. 이메일 문의 시 이메일 주소와 문의 내용은 답변을 위해 처리하며 처리 완료 후 불필요한 정보를 삭제합니다. 민감한 생일·일기 전체를 이메일에 첨부하지 않아도 됩니다.

기존 Onward Korean 이용자

이 앱은 온워드 코리아에서 사주토끼로 변경되었으며 기존 한국어 학습 기능은 더 이상 제공되지 않습니다. 기존 학습 계정과 사주토끼의 기록은 연결하거나 전송하지 않습니다. 이전 서비스에 남아 있는 계정 정보의 삭제 요청은 기존 계정 삭제 안내 또는 support@myonward.cc로 문의할 수 있습니다.

아동과 다른 사람의 정보

다른 사람의 생년월일 등은 동의를 받고 입력해 주세요. 앱은 아동의 개인정보를 별도로 수집하지 않습니다. 보호자는 기기에서 기록을 열람·삭제할 수 있습니다.

변경 안내

기능이나 처리 방식이 바뀌면 이 페이지와 앱 안의 방침을 갱신합니다. 모든 운세는 재미와 자기 성찰을 위한 오락 콘텐츠이며 특정 미래나 결과를 보장하지 않습니다.
